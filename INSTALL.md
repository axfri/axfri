# Установка GitHub Profile README

## 1. Правильное имя репозитория

Профильный репозиторий должен называться **точно так же, как GitHub username**.

Для текущего аккаунта создайте публичный репозиторий:

```text
axfri
```

Итоговый адрес:

```text
https://github.com/axfri/axfri
```

Если username изменится, переименуйте репозиторий и замените `axfri` во всех ссылках файла `README.md`.

## 2. Загрузка файлов

В корень репозитория загрузите структуру без изменений:

```text
axfri/
├── README.md
└── .github/
    └── workflows/
        └── snake.yml
```

Файл `INSTALL.md` публиковать необязательно.

## 3. Запуск snake animation

1. Откройте вкладку **Actions** репозитория.
2. Если GitHub предложит включить Actions, подтвердите включение.
3. Выберите workflow **Generate contribution snake**.
4. Нажмите **Run workflow** → **Run workflow**.
5. Дождитесь успешного завершения. Workflow создаст ветку `output` с двумя SVG-файлами.
6. Обновите страницу профиля. Иногда изображения GitHub CDN появляются с небольшой задержкой.

Workflow также запускается при push в `main` и затем ежедневно автоматически.

## 4. Проверка

Проверьте на странице `https://github.com/axfri`:

- анимированный заголовок;
- бейджи технологий;
- GitHub stats, streak, top languages и activity graph;
- светлую и тёмную версии snake animation;
- ссылки GitHub, Telegram и email.

Если один из внешних статистических виджетов временно не загрузился, сначала откройте URL его изображения напрямую. Такие карточки создаются сторонними сервисами и иногда имеют временные лимиты или сбои.

## 5. Рекомендуемая персонализация

После публикации можно добавить раздел с 3–6 лучшими проектами. Для каждого проекта лучше указать краткую пользу, стек, ссылку на репозиторий и живое демо. Не добавляйте несуществующие проекты или неподтверждённый опыт.
